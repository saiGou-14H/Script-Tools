## 2. 统一验收矩阵

| 编号 | 验收场景 | 预期结果 |
| --- | --- | --- |
| AC-01 | A 用户访问 B 用户任务、日志、凭据和文件 | 服务端拒绝，无敏感信息泄露 |
| AC-02 | 上传脚本、构建依赖、固定版本、执行；使用两份字段不同的输入 Schema；验证 Hook 声明与调用 | 能复现代码、Schema、Hook 与镜像版本；按自身 Schema 校验；缺失必需动作 handler、错误导出或非法返回值明确拒绝；可选 Hook 缺省不影响流程，升级不影响旧任务 |
| AC-03 | Docker 执行时尝试写只读目录、超额内存、超时运行 | 按策略阻止或终止，结果可解释，环境可回收 |
| AC-04 | QEMU+KVM 正常执行及 KVM 不可用 | 正常时记录实际 KVM；不可用且未授权回退时报错 |
| AC-05 | 显式允许 TCG 后启动 | 记录实际 TCG、原因和资源策略；无隐式 Docker 降级 |
| AC-06 | 重复投递同一次调度消息 | 只产生一个运行实例，重复消息可安全确认 |
| AC-07 | 库存依次为未知、无票、有票、有票 | 未知不算无票；有票变化触发通知；重复观察不刷屏 |
| AC-08 | 提交已到景点但客户端超时 | 进入订单核验，不直接再次预约 |
| AC-09 | 私有脚本输出伪造成功或订单号 | 显示未核验，不能冒充已确认订单 |
| AC-10 | 凭据失效、人工更新后恢复 | 等待期间释放环境；恢复时重新校验授权和库存 |
| AC-11 | 暂停任务与取消运行实例 | 分别阻止后续触发和当前后续动作；已发送请求标为待核验 |
| AC-12 | Runner 宕机、重启或租约过期 | 防止旧执行器再次提交，残留环境有回收或隔离记录 |
| AC-13 | 通知服务超时或重复回执 | 受控重试、可追踪去重，结果状态不随通知失败改变 |
| AC-14 | 内网、云元数据地址和非法重定向访问 | 网络边界按策略拒绝，日志中不暴露凭据 |
| AC-15 | 数据恢复后存在未完成预约 | 先对账，不能批量重放提交操作 |
| AC-16 | 三种模式输出正常、错误和伪造平台事件 | 均可关联到正确 Attempt；脚本不能覆盖归属或伪造可信订单状态 |
| AC-17 | SSE 断线、缓存过期、翻页和索引延迟 | 可续读、去重或明确提示缺口；不能冒充“没有日志” |
| AC-18 | 日志包含凭据、超长行和大量输出 | 已定义敏感字段在落盘前脱敏；超限明确截断，采集不阻塞脚本 |
| AC-19 | 篡改日志检索、游标、导出及聚合条件 | 不能访问他人数据，管理员敏感查询留下审计 |
| AC-20 | 采集端重启、中央存储中断和磁盘满 | 重放已持久化记录；暴露丢失或不确定区间，业务对账继续 |
| AC-21 | KVM 回退、无票、未知订单、通知失败 | 各类指标口径正确，不相互混算、不因告警自动重新预约 |
| AC-22 | 多节点同类故障、静默到期和恢复 | 告警聚合、升级和恢复可追踪；确认不等于故障恢复 |
| AC-23 | 监控进程、采集器或告警投递链路故障 | 独立探针发现异常；告警失败可走独立备用通道 |
| AC-24 | 日志到期、用户删除和导出过期 | 查询立即受策略约束，异步清理有结果，备份按自身周期淘汰 |
| AC-25 | 声明负载下日志采集、检索和告警演练 | 形成延迟、丢弃、容量及恢复报告；不能只验收看板截图 |
| AC-26 | 上传两份不同业务及参数的脚本，使用平台从未定义过的动作名 | 无需景点、订单、固定业务 Hook 或后台改码，即可创建、调度、查看结果和通知 |
| AC-27 | 自定义输出、事件和同名动作跨脚本运行 | 按对应版本 Schema 校验；事件按脚本作用域隔离，不冒充平台事件，通知仅到授权用户 |
| AC-28 | 自定义外部写入已发出后超时；无核验器 | 标记副作用未知并转待处理，不盲目重跑；重复投递和恢复不重复执行 |
| AC-29 | 并发触发、手动重放和编辑排队配置 | 唯一 Run/有效租约；旧配置不派发；幂等和修订冲突可区分 |
| AC-30 | 接受结果但 ACK 丢失，后置 Hook/通知/清理失败 | 业务调用仅一次，结果不覆盖，通知与清理分别恢复 |
| AC-31 | 双击恢复、换输入/凭据、跨原窗口 | 一次接续、新快照及授权，原输入不变，不延长原写许可 |
| AC-32 | 未知效果跨周期、独立核验、关闭未知 | 不自动重放；核验独立期限；未知结案仍保留阻塞 |
| AC-33 | 入队后撤权，发送后取消 | 新请求拒绝；在途效果不伪造取消或失败；旧租约无效 |
| AC-34 | 找回密码、邮箱变更、注销和晚到数据 | 会话失效，查询按墓碑拒绝，清理可追踪，数据不复活 |
| AC-35 | 恢复旧备份、队列、节点及对象 | 删除/撤销先恢复；未决先核验，不重复写入；配额对账 |
| AC-36 | 资源残留、逻辑阻塞、接口冲突与闭环告警 | 槽位隔离、配额只释放一次，页面/数据库/监控一致 |
| AC-37 | 接续自身/其他阻塞、终态 Task 结案、下架/撤销版本 | 自身 hold 原子解除，其他阻塞保留；Task 不重开；下架与撤销语义区分 |
| AC-38 | 不同格式产物生成、预览和下载 | 字节及摘要一致，不要求平台内置所有格式转换器，无旅游参数依赖 |
| AC-39 | on_outputs 超时或部分失败、缺少必需项 | 生成状态明确，已接受业务结果不变，不重跑动作 |
| AC-40 | 上传、产物及批次重复/冲突、ACK 丢失 | 同内容幂等，异体冲突；逻辑通知不重复 |
| AC-41 | 越权/跨调用引用、路径越界、超限、伪造元数据 | 服务端拒绝，文件正文及其他用户数据不泄露 |
| AC-42 | 多渠道推送、附件未就绪/删除、退订与发送超时 | 附件依赖、渠道权限及投递状态准确，失败不重跑脚本 |
| AC-43 | 产物生成时撤权、孤儿回收、过期、删除及备份恢复 | 独立权限失效、回收有证据、配额不重复释放、数据不复活 |
| AC-44 | 长期运行、多次产物及推送、超过短任务默认时长 | 同 Run/环境持续，续租有效，多个同名文件独立保留，不覆盖旧批次 |
| AC-45 | 同批重投、新批再次输出、检查点事务及故障重连 | 去重范围正确，旧游标拒绝，没有只保存游标或只发布批次 |
| AC-46 | 停止、撤权、失联、资源限制及恢复/升级 | 有界 STOPPING，短权限失效；合格条件才 safe_resume，未知不重放 |
| AC-47 | 旧脚本不同输入、可选字段、凭据与命令字符映射 | Schema 先校验、参数独立传递；无隐式类型变更、越权凭据或隐藏必填 |
| AC-48 | 草稿编辑、依赖错误、远程更新及物化竞态 | 封存内容不改；更新为候选；构建/发布/绑定分开，错误定位准确；远程部分 P1 验收 |
| AC-49 | legacy 多批文件、采集中修改、同键重投和桥接通知 | 真实文件校验、批次去重和本人渠道有效；不授予面板 API，不重跑业务补产物 |
| AC-50 | 兼容进程长期运行、停止、失联及背压 | 使用原有租约与输出限额，不自动重启；进程完成与业务结果分开 |
| AC-51 | 计划预览、手动碰撞、复制任务和本次日志入口 | 同一规则解析、不重叠；复制为草稿并重新绑定授权，不展示旧 Run 日志 |
| AC-52 | 排队/准备/执行耗时、时钟异常和不同能力脚本 | 数据来源明确；无首请求证据时不显示虚构延迟；只展示实际接入能力 |

## 3. 端到端与竞态场景

公共前置：两个测试用户 A/B；旅行场景关闭；本地受控 HTTP 模拟服务支持请求计数、延迟、断连和结果查询；两个输入字段及动作名不同的脚本；Docker/KVM/TCG 节点；全部使用合成凭据。示例域名 `.invalid` 仅用于静态文件，集成测试替换为批准的模拟服务。每个场景记录代码/Schema/镜像摘要、配置、操作、数据库检查与外部请求计数。

| 编号 / 需求 | 操作步骤 | 通过标准与数据库检查点 |
| --- | --- | --- |
| E2E-01 / AC-26、REQ-039 | A 上传两份不同 Schema 与动作名脚本→封存构建→私有运行→B 购买已上架服务并使用一次权益 | 无旅行字段；两套输入输出分别校验；B 只能访问本人 Run/结果；版本摘要固定 |
| E2E-02 / AC-29、REQ-042 | 并发投递同一到期计划与同键手动请求；重复领取消息；编辑待领取配置 | 计划一个 Run、手动一个 Run、单有效租约；旧未领取 Run 作废；唯一约束实际生效 |
| E2E-03 / AC-30、REQ-043 | 模拟写入完成后提交结果，丢弃接受 ACK；after_action 抛错；通知与清理各失败一次 | 外部写入计数为 1；execution_results 一条；SUCCEEDED 不被附加错误覆盖；通知/清理各自重试 |
| E2E-04 / AC-31、REQ-044 | 返回 ACTION_REQUIRED；两个页面用同修订同时恢复，再用同键异体恢复 | 一个 continuation、一个新有效 Attempt；原 input 不变；重复返回原结果、冲突明确；周期不重复触发 |
| E2E-05 / AC-28、AC-32、REQ-045 | 外部写入后断网并杀 Runner；无核验器；连续跨过三个触发时刻 | UNKNOWN+WAITING_INPUT、活跃 hold；写入计数保持 1；环境回收独立；关闭后为 CLOSED_UNRESOLVED 且 hold 不误解除 |
| E2E-06 / AC-32、REQ-045 | 同上但配置授权只读核验器；原执行期限过期；核验查到结果 | 不取得写许可；RESOLVED 与来源记录；Run 按结论结束；未知阻塞只在有证据后解除 |
| E2E-07 / AC-33、REQ-046 | 排队后撤销版本/凭据或冻结账号；另在请求已发出时取消 | 前者无新增请求；后者保留可能效果并核验/转人工；旧代数请求拒绝；不伪造 CANCELLED |
| E2E-08 / AC-34、REQ-047 | 找回密码、变更邮箱、注销；删除过程中重放晚到事件/日志，模拟存储清理失败 | 旧会话失效；查询按墓碑拒绝；步骤可重试；晚到数据不复活；关闭后仅可查看受限进度 |
| E2E-09 / AC-35、REQ-048 | 恢复旧备份、旧队列和旧节点；补齐删除台账，再开放服务 | 旧租约无权；未决先核验；数据不复活；外部写入计数不增加；配额可对账 |
| E2E-10 / AC-27、REQ-040 | 重投同 event_key、伪造平台事件/他人收件人，邮件商响应超时 | 同调用同事件仅一条；异体冲突；越权拒绝；通知 UNKNOWN 不改变业务结果 |
| E2E-11 / AC-02、REQ-005 | 缺 input_schema、未注册 default/resume action、无效输出、异版本 Schema、复杂 JSON 输入 | 上传/执行在正确阶段拒绝；错误不回显秘密；不强制任何景点字段；无效结果结合效果证据判定 |

## 9. 架构验收清单

- 关闭旅行场景，两份不同业务、动作和输入输出的脚本仍可独立完成上传、运行、结果与通知闭环。
- 自定义动作来自脚本版本清单，不受封闭业务枚举限制；通用 HTTP 无需逐接口新增平台连接器；核心表无必填旅行外键。
- 不确定的自定义外部写入不自动重跑；没有核验器时可进入人工处理；日志与指标不因任意动作名或事件名产生无界标签。
- 以下涉及库存、预约和订单的项目仅为旅行场景验收，不作为通用脚本接入条件。

- 三种模式的请求值、实际值、策略版本和回退原因均可查询。
- KVM 缺失且未允许 TCG 时失败；允许回退时实际标为 TCG；不发生 Docker 降级。
- Docker 和 QEMU 脚本均不能取得宿主 Docker socket、其他用户文件或平台数据库凭据。
- 队列重复投递不重复创建 Run；过期租约不能取得新的预约提交许可。
- 订单可能已提交时进入核验，不以进程超时自动重试预约。
- 兼容脚本自报订单保持未核验，不绕过可信连接器的成功判定。
- 不同脚本使用各自发布者 Schema；必填、类型、嵌套和额外字段规则生效，输入示例通过相应校验；Schema 升级不改变旧任务参数定义，平台元数据不混入业务输入。
- Hook 清单与能力一致；必选/可选规则、调用顺序、超时及错误行为通过[脚本、构建和输入输出协议](./08-脚本开发规范.md#manifest)验收；生命周期 Hook 不授予提交权限，不代替宿主资源回收。
- 客户机磁盘、网络、临时令牌和文件在结束后可验证清理；清理失败进入隔离状态。
- 数据恢复后先核验未决预约，运行方式统计和通知记录可继续追踪。
- 在已声明的硬件和负载条件下分别验证三种模式的容量与调度指标。
- 日志检索、SSE、游标、导出和统计均经过账号归属校验；不存在额外租户模型。
- 脱敏、重放、截断、磁盘满、采集缺口、告警投递和删除均有演练证据。
- 监控不可用不会被显示成业务正常；告警与数据恢复不能重放未知预约。

补充验收：REQ-042～061 / AC-29～52 按[系统不变量](./02-系统架构与详细设计.md#invariants) E2E-01～26 执行，覆盖结果 ACK、双击接续、周期阻塞、撤权竞态、未知结案、账号注销、跨存储恢复和配额释放。协议示例静态通过不等于这些端到端用例通过。

接入补充验收：ADP-01～10 与 E2E-23～26 覆盖映射、封存、旧通知、多次文件交接、长期进程及任务体验。源码参考基线和复用边界见[官方参考与工程落地](./02-系统架构与详细设计.md#references)；P1 远程获取不作为 P0 本地脚本运行前置。
