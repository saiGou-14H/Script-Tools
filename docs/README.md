# Script Tools 文档导航

项目正式名称为 **Script Tools**，工程包使用 `script-tools` 和 `@script-tools/*`。2026-11-14按用户决定统一产品界面、API文档、工程配置和现行文档名称。历史原型图片的品牌文字可追溯到生成时版本，当前前端以本名称为准。

版本：V3.0 / 2026-11-14。面向个人用户的商业化通用脚本管理、发布、部署与付费使用平台；门票代抢是业务场景之一。用户可上传不同用途脚本，自用或发布成服务，也可购买他人已部署服务。首期只按次付费；景点以免费预约为主，门票0元与脚本服务费分别表达。

四工作区：游客、消费者、脚本发布者、平台管理员。同一账号可消费和发布，不建设企业组织或人工审核工作流。平台服务订单、脚本执行、外部预约订单和资金事实独立，商业化不是可选后续模块。
